# 個資去識別化系統 (de-ID Web)

純前端執行的個資去識別化與反向還原 Web 工具。

> **⚠️ 免責聲明：**
> 本工具為非營利開源工具，可能因特殊排版、罕見語境或特殊符號等情形而發生疏漏或誤判。請使用者務必自行再次核對審查。

---

## 🌟 核心特色

1. **100% 純瀏覽器本地運算**：
   - 所有的正則標註、斷詞、去識別化與可逆對照演算法，**完全在用戶端瀏覽器記憶體內執行**。
   - **絕不主動發送任何網路請求或上傳至外部伺服器**，即便離線或無網路環境，系統依然能正常運作。
2. **語意一致性別名化（Consistent Pseudonymization）**：
   - 採用結構化代號（如 `[自然人_1]`、`[醫療機構_1]`、`[金融帳號_1]`）。
   - 同一主體在全篇多次出現時維持唯一代號，維持文章邏輯與主體關聯性。
3. **特定主體與事實保留**：
   - 保留病名、用藥、處置、損害金額、法條依據等文字脈絡，僅針對特種個資進行識別與代號替換。
4. **雙向可逆映射（De-ID & Re-ID）**：
   - 本地端可下載 `.mapping.json` 對照字典（內含原始對照，請妥善保管）。
   - 提供「反向還原」分頁，可匯入對照字典將代號文字還原回原始內容。

## 🛠️ 支援識別範圍

| 類別 | 包含項目 | 範例替換代號 |
| :--- | :--- | :--- |
| **訴訟關係人與自然人** | 原告、被告、訴訟代理人、主治醫師、具狀人、撰狀人、證人、一般自然人 | `[自然人_1]`、`[原告_訴訟關係人_1]` |
| **法定身分證件** | 臺灣身分證號 (合法 Checksum)、居留證號、外國護照、健保卡號 | `[身分證號_1]`、`[居留證號_1]` |
| **金融與營利事業** | 銀行帳號、郵局帳戶、信用卡號 (Luhn 檢核、含 Visa, Master, JCB, AE)、營利事業統一編號 | `[金融帳號_1]`、`[信用卡號_1]`、`[統一編號_1]` |
| **聯絡通訊** | 手機號碼 (09xx)、Email 電子信箱 | `[手機_1]`、`[電子郵件_1]` |
| **不動產與地址** | 精確門牌住址 (可選保留管轄縣市)、地段地號建號、車牌 | `[地址_1]`、`[地號建號_1]` |
| **醫療特種個資** | 醫學中心/醫院/診所名稱、病歷號碼 (Chart No. / MRN) | `[醫療機構_1]`、`[病歷號_1]` |
| **既有遮蔽標記** | 法院裁判書之「甲○○」、「王○○」、「A女」歷史代號 | 統一重構為 `[當事人_法院遮蔽代號_1]` |

## 🚀 GitHub Pages 啟用方式

本專案採用純靜態根目錄託管：
1. 推送完成後，在 GitHub 進入該儲存庫的 **Settings** -> **Pages**。
2. 在 **Build and deployment** 下方的 **Source** 選擇 **Deploy from a branch**。
3. 在 **Branch** 選擇 **`main`** 分支，目錄保持 **`/(root)`**，點擊 **Save**。
4. 完成發布後即可透過 GitHub Pages 網址直接在瀏覽器使用。
