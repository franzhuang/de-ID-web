# 臺灣法律文書 / 病歷 / 財務個資 離線去識別化系統 (de-ID Web)

專為**律師、法官、檢察官、法務人員及醫療爭議處理團隊**打造的**高安全性離線個資去識別化與反向還原 Web 系統**。

---

## 🌟 核心特色

1. **100% 純瀏覽器本地運算（Zero Data Leakage）**：
   - 所有的正則標註、斷詞、去識別化與可逆對照演算法，**完全在用戶端瀏覽器記憶體內執行**。
   - **絕不發送任何網路請求或上傳至伺服器**，即便斷開 Wi-Fi / 拔掉網路線，系統依然能正常運作。
2. **語意一致性別名化（Consistent Pseudonymization）**：
   - 解決司法院裁判書公開系統滿篇「○○○」導致外部 LLM 混淆主體的痛點。
   - 採用結構化代號（如 `[原告_訴訟關係人_1]`、`[醫療機構_1]`、`[金融帳號_1]`），同一主體在全篇多次出現時維持唯一代號，方便 ChatGPT / Claude / Gemini 準確分析法律事實。
3. **法律攻防事實完整保留**：
   - 醫療糾紛：病名（如急性心肌梗塞）、用藥、手術處置等攻防重點**完整保留**，僅遮蔽醫療機構、病歷號與醫師名。
   - 訴訟攻防：損害賠償金額、借貸金額、法條依據、訴訟時序完整保留，僅遮蔽出生年月日等特種個資。
4. **雙向可逆映射（De-ID & Re-ID）**：
   - 本地端一鍵下載 `.mapping.json` 機密字典（切勿上傳外部）。
   - 當外部 LLM 回覆爭點分析或草擬書狀後，可在「反向還原」分頁一鍵還原回真實當事人姓名。

| **訴訟關係人** | 原告、被告、訴訟代理人、主治醫師、具狀人、撰狀人、證人 | `[原告_訴訟關係人_1]`、`[被告_訴訟關係人_1]` |
| **法定身分證件** | 臺灣身分證號 (合法 Checksum)、居留證號、外國護照、健保卡號 | `[身分證號_1]`、`[居留證號_1]` |

| **不動產與地址** | 精確門牌住址 (可選保留管轄縣市)、地段地號建號、車牌 | `[地址_1]`、`[地號建號_1]` |

## 🚀 GitHub Pages 啟用方式

本專案採用最標準的純靜態根目錄託管，免任何複雜工作流：
1. 推送完成後，在 GitHub 進入該儲存庫的 **Settings** -> **Pages**。
2. 在 **Build and deployment** 下方的 **Source** 選擇 **Deploy from a branch**。
3. 在 **Branch** 選擇 **`main`** 分支，目錄保持 **`/(root)`**，點擊 **Save**。
4. 稍等約 30 秒至 1 分鐘，GitHub Pages 即可完成發布，透過：
   👉 **`https://franzhuang.github.io/de-ID-web/`**
   直接在任何電腦、筆電或手機瀏覽器公開使用！
